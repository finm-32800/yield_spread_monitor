How this page is made

  1. Every day at 22:00 UTC, after FRED posts the day's update, a GitHub Actions workflow pulls the newest 10-year and 2-year yields from the FRED API, with an API key stored as a repository secret.
  2. It adds the new days to the history: one CSV of dates and spreads, kept on the repository's monitor-history branch, one small commit a day. The main branch holds only code.
  3. It rebuilds this page and publishes it on the gh-pages branch, which GitHub Pages serves.
